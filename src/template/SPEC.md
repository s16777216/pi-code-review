# src/template

## Purpose

The built-in text of the comments that `publish` writes. The build
copies `FINDING.md` and `RESOLVED.md` to `dist/template`.

## Contents

- `FINDING.md`: the default text of one finding in a comment.
- `RESOLVED.md`: the default text of the reply to a discussion
  declared fixed.

## Capabilities

- `review-output`: `openspec/specs/review-output/spec.md`
